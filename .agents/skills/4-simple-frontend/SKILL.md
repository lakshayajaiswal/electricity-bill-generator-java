# Rules

- Use HTML, CSS and vanilla JavaScript.
- No React or frontend frameworks.
- Keep frontend files separate.
- Create simple input forms.
- Accept consumer details.
- Accept watts and usage hours.
- Accept billing days.
- Include Generate Bill button.
- Display the Java backend response.
- Provide a printable electricity bill.
- JavaScript must not calculate electricity bills.
