# Rules

- Use Java 17 or newer.
- Use Java only for backend.
- Use built-in Java HttpServer.
- Keep backend in one Main.java file.
- Use only necessary methods.
- Avoid unnecessary classes and interfaces.
- No Spring Boot or external frameworks.
- No external dependencies.
- Avoid complicated programming concepts.
- Use simple if-else conditions.
- Avoid code duplication.
- Keep code short, readable and understandable.
- Never add unnecessary features.
- Do not follow arbitrary line limits.
- Every line must have a purpose.
