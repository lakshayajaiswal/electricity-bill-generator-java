# Rules

- Write beginner-level Java code.
- Explain every method.
- Use meaningful variable names.
- Add simple comments.
- Avoid advanced programming concepts.
- Explain each important line.
- Explain how frontend communicates with Java.
- Explain electricity unit calculations.
- Explain bill generation.
- Prepare teacher viva questions.
- Never generate code the student cannot explain.
