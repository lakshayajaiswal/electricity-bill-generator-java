# Rules

- Accept power in watts.
- Accept usage hours per day.
- Accept billing days.
- Calculate units using:

  Units = (Watts * Hours * Days) / 1000

- Calculate electricity charges using per-unit tariff.
- Add fixed charges if applicable.
- Calculate final payable amount.
- Round currency to two decimal places.
- Validate negative and invalid inputs.
- Keep calculation logic simple.
- Perform all calculations in Java.
- Do not calculate bills using JavaScript.
